# 04 — UI

App: `apps/desktop` (Nuxt SPA (same Nuxt build as Lumen) in Tauri 2). UI kit in `apps/desktop/app/ui`, exported from `~/ui`. Explicit imports only.

## Design system

The design system is a copy of Lumen's: `packages/design` is `@lumen/design` with the accent changed to blue, and `app/ui` is Lumen's UI kit. Every token keeps its name and value except:

- `accent.default`, `accent.hover`, `accent.pressed`, `accent.muted`, `accent.soft`, `accent.fg`: a blue ramp. `accent.fg` must reach WCAG AA (4.5:1) on `accent.default`.
- Brand gradients use blue stops instead of orange.

## Workspaces

| Group | Workspace | Route | Purpose |
|---|---|---|---|
| Perform | **Play** | `/` | Setlist rail, song lanes with waveforms, section strip, transport, tempo, key, click |
| Perform | **Mixer** | `/mixer` | Faders, mute and solo, bus meters, routing matrix |
| Build | **Arrange** | `/arrange/:songId` | Sections, markers, cue events, tempo map |
| Library | **Songs** | `/songs` | Import stems, analysis, metadata |
| Library | **Setlists** | `/setlists` | Order songs, transitions, pads |
| System | **Settings** | `/settings` | Audio device, rig, MIDI, Link, timecode, Lumen |
